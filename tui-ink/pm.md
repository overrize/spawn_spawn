# PM 空回复问题记录

## 问题描述
用户提问时，系统会输出多个 PM 回复标记，但只有一个包含实际内容，其余为空。

## 根本原因
PM 在同一轮回复中不小心输出了多行 JSON（例如 step 和 message 分成了两行），系统将每一行都当作一次独立回复。如果某一行格式不完整或不是有效 message 类型，会被丢弃，但用户仍会看到空的 PM 标记。

## 表现特征
- 一次用户提问后出现多个 "PM: " 前缀
- 只有一个包含有意义的文字内容
- 其他行显示为空或仅含时间戳

## 应对措施
1. PM 必须严格遵守“每轮只输出一个紧凑单行 JSON”的协议约束
2. 所有需要传递的信息（step、message、tool.call 等）应合并到同一个 JSON 对象中
3. 如果用户发现空回复现象，可直接提醒 PM 检查输出格式
